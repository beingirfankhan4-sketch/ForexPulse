Create a modern mobile-first social media app for Forex traders, inspired by the usability and content flow of Instagram, but with a unique original brand and interface.

App name: ForexPulse

Main Goal

Build a social platform where Forex traders can easily create, share, discover, and engage with trading-related content. The platform should help educational and market-analysis posts reach the right audience through a smart recommendation system.

Core Features

1. Home Feed

- Instagram-style scrolling feed
- Trading posts with images, charts, short videos, and text
- Like, comment, share, save, and follow buttons
- "For You" and "Following" feeds
- Trending Forex posts section
- Recommended traders to follow

2. Create Post
Allow users to publish:

- Forex market analysis
- Trading charts
- Educational posts
- Trading psychology content
- Short videos/Reels
- Market news
- Trade ideas
- Screenshots with captions

Post composer should support:

- Image/video upload
- Caption
- Hashtags
- Forex pair selection such as EUR/USD, GBP/USD, USD/JPY, XAU/USD
- Bullish/Bearish/Neutral sentiment
- Optional entry, stop-loss and take-profit fields
- Educational/disclaimer label

3. Viral/Discovery System
Create a recommendation algorithm that ranks content based on:

- Engagement rate
- Likes
- Comments
- Shares
- Saves
- Watch time
- Post quality
- Recency
- Relevance to user's followed currency pairs
- Hashtag relevance
- User interests

Add a Trending page showing currently popular Forex content.

Do NOT guarantee that a post will go viral. Instead, provide a Post Performance Score that estimates content engagement potential.

4. Reels
Create a short-video section similar to Instagram Reels:

- Vertical full-screen videos
- Like/comment/share/save
- Follow creator
- Trending audio support
- Forex-related hashtags
- Swipe-based discovery

5. Trader Profiles
Each profile should contain:

- Profile photo
- Username
- Bio
- Followers/following
- Posts
- Reels
- Saved educational content
- Favorite currency pairs
- Trader reputation/engagement statistics

Do not display fake profitability or claim that a trader is guaranteed to make money.

6. Smart Hashtag System
Automatically suggest relevant hashtags based on the post:
#Forex
#ForexTrading
#Trading
#PriceAction
#TechnicalAnalysis
#GoldTrading
#EURUSD
#GBPUSD
#USDJPY
#XAUUSD

7. Search & Explore
Allow users to search:

- Traders
- Currency pairs
- Hashtags
- Posts
- Reels
- Educational topics

Create an Explore page with personalized Forex content.

8. Notifications
Include notifications for:

- Likes
- Comments
- Follows
- Shares
- Mentions
- New followers
- Trending-post milestones

9. Safety & Moderation
Add:

- Report post
- Block user
- Mute user
- Spam detection
- Scam detection
- Financial-risk disclaimer
- Community guidelines
- Moderation dashboard

Clearly label content as educational/informational and avoid presenting the platform as a financial-advice service.

UI/UX

Design should feel:

- Premium
- Modern
- Fast
- Professional
- Mobile-first
- Easy to use

Use a clean dark trading-inspired interface with excellent typography, smooth animations, rounded cards, bottom navigation, and visually strong charts.

Bottom navigation:
Home | Explore | Create | Reels | Profile

Admin Dashboard

Create an admin panel for:

- User management
- Post moderation
- Report management
- Trending content
- Hashtag analytics
- Engagement analytics
- Suspicious-account detection
- Platform statistics

Important

The app should be an original product, NOT a direct copy of Instagram's branding, logo, proprietary assets, or exact interface.

Build the application with scalable architecture, responsive UI, authentication, database integration, media uploads, search, notifications, recommendation logic, and secure API design.

The final product should feel like "Instagram built specifically for the Forex trading community."
